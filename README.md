# CognitiveRFP — Adaptive Proposal & RFP Agent

> **“Every proposal teaches the next proposal how to win.”**

An AI-powered Proposal & RFP intelligence platform that remembers past proposals, win/loss patterns, client preferences, objections, redlines, and evaluator feedback. It uses persistent cognitive memory to retrieve relevant past experiences, reason over them, and generate improved RFP responses that avoid previously identified mistakes.

---

## 💡 The Core Contrast

* **Generic AI → Remembers nothing → Repeats mistakes**
  * Proposes vague 99.9% uptime with zero financial service credits.
  * Forgets to attach pre-executed Business Associate Agreements (BAAs) for healthcare prospects.
  * Quotes rigid list prices without tiered volume discounting or price-lock commitments.
* **CognitiveRFP → Recalls past experiences → Reasons about them → Generates a better response**
  * Preempts known procurement deal-breakers.
  * Injects 99.99% availability with contractual 10%–50% tiered financial service credits.
  * Pre-attaches SOC 2 Type II audit bridge letters and HITRUST/BAA schedules.
  * Incorporates 36-month price-lock protections and annual unused credit rollovers.

---

## 🧠 Three-Layer Cognitive Architecture

1. **RETAIN (Organizational Memory Bank)**
   * Stores rich structured memories across 6 enterprise verticals (FinTech, Healthcare, Cloud SaaS, Manufacturing, Public Sector, Retail).
   * Captures won proposals, lost bids, pricing redlines, security audits, and evaluator feedback.
2. **RECALL (Multi-Factor Semantic Retrieval)**
   * When an RFP requirement is entered, the engine runs semantic vector scoring weighted by industry affinity (1.25x–1.5x) and client matching.
   * Ranks past precedents and outputs relevance scores (e.g. 96%) with human-readable "Why Relevant" explanations.
3. **REFLECT (Cross-Memory Strategic Synthesis)**
   * Synthesizes higher-order strategic doctrine from multiple independent memory signals.
   * Compiles recommended contractual action checklists and enforces active organizational guardrails.

## 🚀 Key Features

* **Response Studio**:
  * Dual generation pipeline: **Stateless Baseline** vs **Adaptive Hindsight**.
  * Animated 7-stage cognitive generation pipeline (`Input` → `Recall` → `Memories` → `Reflect` → `Assembly` → `LLM` → `Output`).
  * Split-screen side-by-side proposal comparison with token telemetry, latency meters, and diff highlighting.
  * Potential Known Deal Risks callout box identifying vulnerabilities in generic AI responses.
  * 6 one-click realistic enterprise RFP presets.
* **Hindsight Memory Bank**:
  * Retain new proposal experiences with industry, tags, deal size, and narrative.
  * 4 quick learning triggers (Instant seed buttons for FinTech SLA, Healthcare BAA, SaaS Pricing, Support Escalation).
  * Searchable memory database with filters and active guardrail rules.
  * **Synthesize Strategy**: Automatic extraction of high-conviction guardrails with celebration animations.
* **Proposal Intelligence Analytics**:
  * High-level metrics: **+18.4% Win Rate Lift**, **-75% RFP Turnaround Time**, **12 Active Guardrails**, **148 Experiences Retained**.
  * Interactive visualizations: Baseline vs Adaptive performance over time, top deal breakers, memory growth curve, and vertical intelligence breakdown.
* **Interactive Architecture Page**:
  * Full clickable execution flow diagram with deep inspector showing technology stack, stage latency, input contracts, and output schemas.
* **Enterprise Design System**:
  * Dark-first theme (slate-950, slate-900, emerald accents, amber baselines, cyan/indigo highlights).
  * Fully responsive across desktop, laptop, tablet, and mobile.

## 🛠️ Tech Stack

* **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti.
* **Backend**: Node.js, Express, REST APIs, JSON-file persistence.
* **Cognitive Engine**: Multi-factor semantic scoring, n-gram TF-IDF matching, cross-memory reflection synthesizer, dynamic prompt assembly.
* **Inference Compatibility**: Groq Llama 3.3 70B, Google Gemini, Anthropic Claude, and Local Deterministic Cognitive Engine.

## 🏃 Getting Started

* Node.js v18+ and npm installed

npm run dev
